# Arcus Input Types UI Library

This is a custom UI library for Morpheus that provides multiple custom OptionType components built with React, Vite, and Focus-UI.

## Architecture

The library is structured as a modern JavaScript project that:

- Uses **Vite** for fast builds and bundling
- Uses **React** (from global scope) for component development
- Uses **Focus-UI** components for consistent styling and accessibility
- Registers multiple custom input types with the Morpheus component registry

## Components

### 1. Custom Slider (`custom-slider`)

An interactive slider control for numeric values with configurable min/max/step and optional unit labels.

**Use cases:** Volume controls, percentage inputs, resource allocation

### 2. Custom Toggle (`custom-toggle`)

An enhanced toggle switch with customizable on/off labels.

**Use cases:** Feature flags, enable/disable options, binary configuration

### 3. Custom Rating (`custom-rating`)

A star rating interface with hover preview and customizable icons.

**Use cases:** Priority levels, quality ratings, importance indicators

## Development

### Prerequisites

- Node.js 20.x or higher
- npm 10.x or higher

### Build Process

The build is integrated into the Gradle build:

```bash
./gradlew build
```

This will:

1. Install npm dependencies
2. Run Vite to build the UI library
3. Output `arcus-input-types.js` to `src/assets/js/`
4. Package the plugin with the built assets

### Manual Build

To build the UI library separately:

```bash
cd morpheus-system-example
npm install
npm run build
```

### Development Mode

For active development with hot reload:

```bash
npm run dev
```

## How It Works

1. **Build Time**: Vite bundles all components from `ui-src/` into a single IIFE (Immediately Invoked Function Expression) that externalizes React
2. **Load Time**: Morpheus loads the bundled JavaScript through the `ArcusInputTypeLibraryProvider`
3. **Registration**: Each component self-registers with the Morpheus component registry
4. **Usage**: Components are available as custom OptionTypes in forms, wizards, and workflows

## Adding New Components

To add a new custom OptionType:

1. Create a new component file in `ui-src/components/`:

    ```jsx
    import React from "react";

    const MyComponent = (props) => {
    	// Component logic
    	return <div>...</div>;
    };

    MyComponent.register = () => {
    	window.Morpheus.components.register("my-component", MyComponent, {
    		type: "optionType",
    		name: "My Component",
    		// ... registration config
    	});
    };

    export default MyComponent;
    ```

2. Import and register it in `ui-src/main.js`:

    ```javascript
    import MyComponent from "./components/MyComponent";

    const components = [
    	CustomSlider,
    	CustomToggle,
    	CustomRating,
    	MyComponent, // Add here
    ];
    ```

3. Rebuild the project

## Configuration

### Vite Configuration (`vite.config.js`)

- **Library mode**: Builds as an IIFE for browser globals
- **External React**: Uses React from `window.React`
- **Output**: Single file to `src/assets/js/arcus-input-types.js`

### Gradle Integration (`build.gradle`)

The `buildUILibrary` task:

- Runs `npm install` automatically
- Executes `npm run build`
- Ensures UI is built before Gradle assets are processed

## Dependencies

### Runtime (Peer Dependencies)

- **React 18+**: Must be available on `window.React`
- **Focus-UI**: Must be available on `window.FocusUI`

### Build Dependencies

- `vite`: Build tool and dev server
- `@vitejs/plugin-react`: React support for Vite
